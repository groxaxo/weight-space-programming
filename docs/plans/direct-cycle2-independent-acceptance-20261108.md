## Outcomes, uncertainty, and immutable decision

For each case/arm, `Y=1` only if the attributed generation completes with an
observed allowed EOS, strict JSON/finalization checks pass, the Python compiles,
and all twelve protected executable checks pass. Otherwise `Y=0` for a valid
model attempt. Preserve original tokens/bytes, actual token count, EOS IDs, stop
reason and censor flags. EOS at the last allowed token is complete. A token cap
without EOS, fixed generation-wall timeout, unexplained short stop, invalid
response, compilation error, or test failure is a failure; never drop it from
the denominator. Record each censor/error subtype separately. A cap flag cannot
override contradictory raw EOS evidence. Do not use output length, operator
logits, likelihood, or the final string as the primary metric.

A missing attempt, attribution mismatch, unstable parent/source, oracle fault,
container/resource failure, unsupported runtime, failed postcheck, or lost raw
record makes the batch invalid and `independent_paired_quality: NOT_RUN`, with
partial evidence retained. It cannot become a pass. Do not silently rerun or
repair an already exposed final set; any set used in an invalid or failed final
attempt is retired from future confirmation. A valid completed batch can score
censored model outputs as failures and must report them explicitly.

The primary metric is paired executable pass-rate gain. Let R be original-fail /
candidate-pass rescues, L original-pass / candidate-fail regressions, B both-pass,
and F both-fail. Require `R+L+B+F=24`; report both arm rates and
`delta=(R-L)/24`. Three cases per family make the overall rate equal to the
macro-family mean. For each family calculate its signed pass difference.
Let K be the number of positive families and M the number of nonzero families;
the exact one-sided sign probability is
`sum(comb(M,j), j=K..M) / 2**M`, or 1 when M is zero.

Accept this bounded BF16 screen only if every integrity/completeness gate passes,
delta is at least 0.125 (12.5 percentage points), L is zero, at least five of eight
families improve, none worsens, and the exact family sign probability is at most
0.05. Thus five improved and three tied families with no case regression have
directional probability 1/32 and require at least five rescues; the nominal
12.5-point threshold alone is insufficient. No hidden threshold is tuned from
the surgeon's development scores. Also require zero unexplained losses on the
separately frozen exposed regression set (the fourteen previous development
checks plus the exact selected HE9/client fixture manifests). They remain exposed
regressions and never enlarge the independent denominator.

Report the exact one-sided 95% Clopper-Pearson lower bound for the probability
of a positive family difference conditional on a nonzero difference (zero when
K is zero). Acceptance requires this lower bound to exceed 0.5, equivalent here
to the directional test at the stated alpha; include K, M, all eight-family
counts and full 24-case denominator. This uncertainty statement assumes the
registered distinct-family sampling/exchangeability model. It is not a confidence
bound on population pass-rate magnitude. With eight families there is limited
power, ties reduce effective sample size, and neither a small positive gain nor
non-significance establishes equivalence. No broad quality or native deployment
claim follows even from a screen pass. Failed valid acceptance is `REJECT` and
ends selection on that set. No qualified candidate or no run is `NOT_RUN`.

## Prospective CLI contract

The normative, currently unimplemented entry point is
`python3 -m weight_space_independent_acceptance`. It must implement:

1. `verify-freeze --interface PATH --freeze PATH --out RECEIPT`: authenticate
   inputs and return `ADMITTED` or `REJECTED`, without creating hidden cases or
   running a model.
2. `seal-tests --admission RECEIPT --private-root DIR --out PUBLIC_RECEIPT`:
   independently author/check/seal all private content after candidate freeze;
   return opaque IDs, commitments and counts only; no model calls.
3. `run-paired --admission RECEIPT --sealed-set PUBLIC_RECEIPT --resource-admission
   PATH --private-root DIR --out PUBLIC_RESULT`: run exactly the complete pair
   schedule, without an arm selector, replacement candidate, prompt override,
   seed override or resume that regenerates outputs. Existing byte-identical
   trial records may only be reconciled, never regenerated or overwritten.
4. `audit-aggregate --public-result PATH --private-root DIR --out PUBLIC_AUDIT`:
   recompute the frozen rule independently from retained records, with no model
   calls and only the permitted aggregate on stdout/output.

Exit 0 means the requested engineering operation completed, never scientific
acceptance by itself. A public result uses explicit `PASS_BOUNDED_BF16_SCREEN`,
`REJECT`, or `NOT_RUN`; incomplete runs cannot emit a pass. Until a new explicit
frozen-candidate invocation, this custodian stops after these two protocol files.
