This change implements one forward-only research entry point without importing

Use [the unified lab guide](../unified-lab.md) for the workflow, schemas, controls,

## Integrated call path

- `scripts/wsp_lab.py`: common CLI; strict protocol/case/tool-history validation;
  source and policy binding; prepare/plan/run/compare/patch-structure/replay.
- `ops/wsp_lab54.py`: shared admission, immutable source/input capture, retained
  containers, cumulative accounting, durable study claim and ordered controls.
- `scripts/wsp_worker.py`: original-parent loader, fresh greedy generation,
  first-stop validation, 64 MLP vectors, actual intervention proof and all-426
  handled-error postchecks. Its host verifier recomputes the applied BF16 result.
- `scripts/wsp_interventions.py`: fixed input/output zero/replace/add hooks;
  prefill/cache separation; exact words; half-strength and two fixed hash-seeded
  random controls, with actual support/norm matching and degeneracy rejection.
- `scripts/wsp_pairs.py`: frozen literal text/JSON assessment, paired raw-record
  outcomes, family rescues/regressions, exact-output locality and optional
  full-vocabulary KL. External-grade aggregation remains a declared-data tool.

The existing parent loader, sparse numeric validator, CPU kernels, source schema
and resource/sandbox primitives are reused. Their historical thirteen producer
files are byte-identical to the prior reviewed bank. New workers bind an extended
twenty-one-file source/policy/catalog manifest. No existing protocol, capsule,
negative verdict, baseline or trained release is rewritten.

The pipeline freezes optional expected answers before a generation and passes
only messages/tools to the model template. It does not leak grading targets into
the model input. A bad no-op stops before treatment, and interrupted attempts
stay charged even when no worker receipt is available. Byte-modified numeric
evidence is rejected. A passing activation-control record cannot admit a weight
candidate: the output explicitly retains `scientific_mechanism_accepted: false`,
`weight_candidate_eligible: false` and `quality_evaluation: NOT_RUN`.
